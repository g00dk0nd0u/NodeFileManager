# 製品コンセプト

NodeFileManager は、フォルダーをグラフィカルなノードとして表現する、自由配置可能な無限ワークスペースを目指します。

- フォルダーを DOM ノードとして表示する
- ファイルシステム階層は、配線を使わず物理的に接続したフォルダーパネルで示す
- 親の下に子パネルを接続し、兄弟は Kanban 風に横方向へ配置する
- ユーザーはノードを自由に再配置できる
- 実ファイルシステムを常にデータの正とする
- 表示位置などのワークスペースレイアウトは、ファイルシステム階層とは独立して永続化する

最初の利用可能版では、選択、階層展開、直接操作、ローカル復元までを細く一周実装します。実機で得たフィードバックを基に、各機能を段階的に深めます。
